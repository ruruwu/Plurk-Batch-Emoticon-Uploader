# 隱私政策

適用工具：Plurk Batch Emoticon Uploader  
最後更新日期：2026 年 11 月 1 日

Plurk Batch Emoticon Uploader 是協助噗友批次上傳表符的 Chrome 擴充功能。本工具為非官方第三方工具，與噗浪官方沒有從屬關係。

本政策說明本擴充功能如何存取、使用、傳送及保存資料。噗浪及圖片服務收到資料後的處理方式，則由各服務自身的政策與條款規範。

## 會處理哪些資料？

| 資料 | 用途 |
| --- | --- |
| 你主動選取的圖片、檔名與檔案類型 | 產生本機預覽，並在你開始上傳後傳送圖片至噗浪。工具不會掃描電腦中的其他檔案。 |
| 你填寫的關鍵字與選取的表符群組 | 將表符新增到指定群組，並設定關鍵字。 |
| 噗浪回傳的群組、收藏、圖片識別碼、圖片網址與關鍵字 | 顯示群組與處理結果，並核對無法確認的新增結果。 |
| 目前噗浪分頁中的表單驗證 token | 向噗浪驗證讀取群組、上傳圖片及新增表符的請求。 |
| 操作來源的分頁識別碼、管理頁網址與無痕狀態 | 檢查請求是否來自允許的管理頁，並處理分頁的暫時冷卻狀態。 |
| 請求狀態、錯誤代碼及等待秒數 | 顯示操作結果、錯誤提示與操作頻率限制。 |

本工具不要求你輸入帳號或密碼，不蒐集瀏覽歷史，也沒有廣告或使用行為分析追蹤。

## 何時讀取及傳送資料？

開啟批次上傳介面或點選「重新整理群組」時，工具會向噗浪讀取表符群組與收藏資料。上傳流程也可能再次讀取這些資料，以更新清單或核對新增結果。

選圖後的圖片預覽在本機產生，不會因為預覽就上傳圖片。按下「開始上傳」後，工具才會將所選圖片、檔名及新增表符所需的關鍵字、群組與圖片識別碼等資料傳送至 `https://www.plurk.com`。

每次 API 請求會按需讀取目前噗浪分頁的表單驗證 token，並將它傳送給噗浪。token 不會傳回批次上傳介面的腳本、不會輸出至程式紀錄，也不會持久保存。本工具沒有使用 Chrome 的 `cookies` 權限直接讀取 Cookie；但瀏覽器仍會依其規則在噗浪請求中附帶登入 Cookie。

## 誰會收到資料？

上傳圖片與表符操作資料會直接傳送到噗浪，不會經過開發者的伺服器。本工具沒有額外的資料收集、廣告或分析服務，也不會出售資料，或將資料用於廣告、信用評估等與批次上傳無關的用途。

群組圖示會從噗浪 CDN（`s.plurk.com`）或噗浪回傳的 HTTPS 縮圖網址載入；後者可能位於其他圖片主機。圖片主機會收到一般連線資訊，例如 IP 位址，以及瀏覽器依規則允許附帶的 Cookie。這些圖片請求已設定不傳送來源頁網址（`no-referrer`）。

## 資料會保存多久？

本擴充功能不使用持久化儲存來保存所選圖片、驗證 token、上傳清單或處理結果。清單、預覽與結果暫存在管理視窗的記憶體中；返回表符管理、關閉管理視窗或重新整理頁面時，清單與結果會清除，無法恢復。移除圖片或清理介面時，也會釋放對應的本機預覽網址。

操作頻率限制所需的分頁識別碼與冷卻時間只保存在背景程式記憶體，背景程式停止後不會保留。瀏覽器及外部圖片服務本身的快取或連線紀錄，不屬於本擴充功能的儲存。

已送往噗浪的圖片與表符不會因為關閉視窗、清除清單或移除擴充功能而自動刪除。若要管理或刪除已新增的表符，請使用噗浪原本的表符管理功能；噗浪端資料的保存與刪除方式依噗浪規定辦理。

## 為什麼需要這些權限？

- **`https://www.plurk.com/*` 網站存取權限**：在噗浪表符管理頁面加入操作介面、取得主頁驗證資料，並向固定的噗浪 API 讀取群組、上傳圖片及新增表符。這項權限的授權範圍涵蓋該主機，並非瀏覽器只允許存取三個 API；目前程式用途限於上述功能。
- **`scripting`**：在發出操作的噗浪分頁主頁中，執行隨擴充功能提供的本機程式，讀取表單驗證 token。

圖片與 API 請求使用 HTTPS。本工具不載入遠端程式碼，也不把驗證 token 透過網頁 DOM 事件傳遞。

## 你可以如何控制資料？

你可以在開始上傳前，選擇要提供哪些圖片、關鍵字及群組，也可以移除不需要的待處理圖片。若不希望工具繼續存取噗浪，可在 Chrome 擴充功能管理頁撤銷網站存取權限、停用或移除本工具。

上傳中的已送出請求仍可能完成，撤銷權限或關閉視窗不會撤銷既有操作。若結果不明，請先到噗浪表符管理查看，避免重複上傳。
