# 專案文案清單

以下為目前程式使用的文案。重複出現的相同文案合併列出；`{變數}` 代表執行時填入的內容，並非原始 JavaScript 語法。主要範圍是擴充功能介面，另附內部錯誤及測試頁文字。README 與技術文件的敘述不列入產品介面文案。

## 可直接貼給 ChatGPT 的改寫需求

請協助優化以下噗浪表符批次上傳擴充功能的文案，使用自然、親切、簡潔的台灣繁體中文。請以「編號／原文／建議文案／調整理由」表格回覆。

- 保留操作意義與所有動態變數，不增加尚未實作的功能或保證。
- 按鈕簡短明確；錯誤提示說明目前情況與使用者可採取的下一步。
- 統一「表符、群組、關鍵字、收藏」等詞彙；若建議更換詞彙，請說明理由並保持一致。
- 「上傳圖片」和「新增表符」是兩個處理階段，請保留階段差異。
- 結果不明時，必須保留「先查看表符管理、避免重複上傳」的提醒。
- 確認圖片與順序的區塊在窄視窗會移到下方，位置描述需適用於不同視窗大小。
- 內部錯誤與測試頁文字請另外評估，不必套用產品介面的語氣。

| N06 | 上傳流程結束的基本結果 | 已新增 {成功數}/{圖片總數} 個表符。 |
| N07 | 全部成功時附加 | 這批都完成了！要上傳下一批，請重新選擇群組和圖片。 |
| N08 | 流程停止時附加 | 上傳已停止，請查看各張圖片的提示。 |
| N09 | 同步失敗時附加 | 暫時無法更新表符清單，請稍後點「重新整理群組」。 |

N06～N09 依結果串接：全部成功附加 N07；未全部完成時，停止則附加 N08，未停止則附加「請查看各張圖片的提示。」；同步失敗另附加 N09，不改變成功數。結果不明時，卡片保留 E09，避免重複上傳。成功狀態加上實際關鍵字後為「已新增：{實際關鍵字}」。

## 錯誤與恢復提示

E10 為確認遭拒絕但原因不明的通用提示，不推定噗幣效期、群組權限、數量、圖片或關鍵字限制；E09 用於結果不明，維持原判斷及重試限制。

E01～E06 來源：`src/batch-view.js`；E07～E11 來源：`src/upload-core.js`。

| 編號 | 出現時機 | 目前文案 |
| --- | --- | --- |
| E01 | 讀群組回傳 401 | 無法確認你是否已登入。請重新登入噗浪，再開啟表符管理。 |
| E02 | 讀群組回傳 403 | 讀取不到群組，請確認已允許擴充功能存取噗浪。如果正在使用無痕視窗，請換成一般視窗再試。 |
| E03 | 讀群組回傳 429 | 操作太頻繁了，請等一下再試。 |
| E04 | 其他群組讀取錯誤 | 暫時讀取不到群組，請稍後點「重新整理群組」。 |
| E05 | 圖片預覽失敗 | 這張圖片無法預覽，請確認檔案能正常開啟，或換一張圖片試試。 |
| E06 | 無法啟動上傳 | 還不能開始上傳，請確認已選好群組，也看看各張圖片的提示。 |
| E07 | 上傳回傳 429 | 操作太頻繁了，上傳已停止，請等一下再試。 |
| E08 | 上傳回傳 401 或 403 | 現在無法繼續上傳，請確認已登入噗浪，而且帳號可以新增表符。 |
| E09 | 上傳結果不明 | 還不確定這張表符是否新增成功。請先到表符管理查看，避免重複上傳。 |
| E10 | 確認被拒絕 | 這張表符沒能新增。請先到表符管理確認是否還能新增，以及所選群組是否可用。 |
| E11 | 429 有等待秒數時附加 | 請至少等 {秒數} 秒再試。 |

有明確等待秒數時，E03 顯示「操作太頻繁了。請至少等 {秒數} 秒再試。」；E07 顯示「操作太頻繁了，上傳已停止。請至少等 {秒數} 秒再試。」，取代「請等一下再試」，避免重複提醒。診斷區顯示「［{錯誤代碼}］」或「［{錯誤代碼}／HTTP {狀態碼}］」，代碼供回報問題使用，不建議當一般文案改寫。
