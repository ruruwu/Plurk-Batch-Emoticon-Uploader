# Plurk Batch Emoticon Uploader

參加噗浪企劃、準備好一整批角色表符，卻得一張一張選檔上傳？這個小工具讓你一次選取多張圖片，確認好表符群組和順序後，再一起交給它依序上傳。

工具直接放在噗浪原本的表符管理頁面裡，不需要另外開啟網站。無論是替角色補齊各種表情，還是把電腦裡存好的表符重新上傳，都能少一些重複操作，多留點時間給創作和噗友互動。

## 主要功能

- **多張一起選**：一次加入多張圖片，也能繼續選檔補進清單。
- **先看再上傳**：預覽圖片、移除不需要的待處理項目，並用「上移／下移」調整順序。
- **整批放進同一群組**：選擇既有的表符群組，不必每張重選。
- **關鍵字自由填**：每張都能各自設定，也可以留空，交給噗浪自動命名。
- **每張進度看得到**：查看哪些表符已新增，哪些還需要確認。

## 安裝方式

目前採手動安裝，未來預計上架 Chrome Web Store。

1. 下載本專案並解壓縮。熟悉 Git 的噗友也可以直接 clone 儲存庫。
2. 在 Chrome 網址列輸入 `chrome://extensions/`，開啟右上角的「開發人員模式」。
3. 點「載入未封裝項目」，選擇含有 `manifest.json` 的專案資料夾。
4. 允許擴充功能存取 `https://www.plurk.com/*`，再重新整理已經開著的噗浪頁面。

之後更新專案檔案時，請到同一個擴充功能管理頁按「重新載入」，再重新整理噗浪。

## 使用方式

1. **登入噗浪**：先確認目前登入的是要新增表符的帳號。
2. **打開工具**：開啟噗浪的表符管理視窗，切換到「上傳」，再點「批次上傳」。
3. **選群組和圖片**：點選這批表符要加入的群組，再從電腦選取多張圖片。
4. **確認清單**：看看預覽、調整順序，並視需要填入每張圖片的關鍵字。
5. **開始上傳**：點「開始上傳」，保持視窗開啟，等待逐張處理完成，再查看各張結果。

全部完成後，重新選擇群組和圖片，就能接著上傳下一批。再次加入圖片時，已成功的項目會從清單移除，尚未完成的項目則會保留。

選圖和預覽時不會上傳圖片；只有按下「開始上傳」，才會送出圖片並新增表符。

## 使用提醒

- **噗浪原本的限制仍然適用。** 本工具不會增加表符數量上限，也不會解除帳號的功能使用限制。圖片大小、尺寸、格式與關鍵字仍須符合噗浪規範，是否接受由噗浪判定。
- **上傳期間請不要關閉表符管理視窗或重新整理頁面。** 目前沒有保存進度的功能，關閉後清單與結果就會消失，但已送出的上傳或新增操作仍可能完成。點「回到表符管理」也會清除目前清單與結果。
- **結果不明時，先到表符管理查看。** 請確認是否已經新增成功，再決定下一步，避免同一張表符重複上傳。
- 一次選取大量圖片會佔用較多記憶體，可以依需要分批處理。

## 常見問題

### 為什麼表符無法上傳？

先確認已登入噗浪、帳號目前可以新增表符，以及所選群組仍可使用。若讀取不到群組，也請確認已允許擴充功能存取噗浪，並使用一般視窗；目前不支援無痕視窗。

工具會略過非圖片檔，但選得到圖片不代表一定符合噗浪的上傳規範。若無法預覽，請先確認檔案能正常開啟，或換一張圖片試試。其他情況請查看該張圖片下方的提示。

### 群組或表符清單沒有更新怎麼辦？

批次上傳介面開啟時會讀取群組，也可以點「重新整理群組」再次讀取。若提示暫時讀取不到，請稍後再試。

上傳結束後，工具會嘗試更新自己的群組資料，但不會直接刷新噗浪原本的收藏畫面。若原生收藏仍顯示舊內容，請等上傳結束後，關閉並重新開啟表符管理視窗。

### 上傳到一半停下來了？

請先看各張圖片的提示。遇到登入、權限、操作太頻繁或無法確認結果的情況，工具會停止後續上傳。

若提示操作太頻繁，請先等候；有顯示秒數時，至少等候指定時間，不要透過重新載入繞過限制。工具不會在等待結束後自動繼續。

若項目已明確顯示失敗，請先確認帳號與群組狀態；處理好問題且「開始上傳」可用時，可再點一次，已成功的項目會跳過。結果不明的項目則須先人工核對。

### 顯示「還不確定是否新增成功」，可以直接再傳一次嗎？

請先到噗浪表符管理確認。連線中斷或回應異常時，操作有可能已經完成，只是工具沒能確認結果。

工具不會直接重送結果不明的項目，也沒有自動解除這個狀態的功能。即使移除項目或重開視窗，已送出的操作也不會因此撤銷，請先核對再重新選圖。

### 可以搬移帳號表符，或幫我新增群組嗎？

目前只支援把電腦中選取的圖片上傳到既有表符群組，每批使用同一個群組。不提供帳號間直接搬移、匯出表符、新增或刪除群組，以及修改群組縮圖的功能。

## 隱私與權限

這是非官方的第三方小工具，與噗浪官方沒有從屬關係。

工具需要存取 `www.plurk.com`，才能在表符管理頁面加入批次上傳介面、讀取群組與收藏資料，並把你選好的圖片新增為表符。另外也需要 Chrome 的 `scripting` 權限，從目前噗浪分頁讀取送出請求所需的驗證資料（表單 token）。不需要在工具裡輸入帳號或密碼。

資料處理方式如下：

- **圖片傳到哪裡？** 按下「開始上傳」後，所選圖片、檔名、關鍵字及目標群組等上傳資料會送到噗浪，沒有額外的資料收集服務或分析追蹤。
- **登入資料怎麼使用？** 驗證 token 只用於向噗浪發出請求，不會傳回介面腳本、寫入紀錄或持久保存。工具沒有使用 `cookies` 權限直接讀取 Cookie，但瀏覽器仍會依規則在請求中附帶噗浪的登入 Cookie。
- **預覽與進度存在哪裡？** 所選圖片的預覽在本機產生，清單與處理結果只暫存在記憶體中，不會保存成可恢復的上傳紀錄。
- **群組圖示從哪裡載入？** 會從噗浪 CDN 或噗浪回傳的 HTTPS 縮圖網址載入。這些圖片主機會收到一般圖片請求資訊，例如 IP 位址；程式已設定不傳送來源頁網址。

完整資料處理說明請見 [隱私政策](PRIVACY.md)；技術細節請見 [API 接線紀錄](docs/API-CONTRACT.md) 與 [權限審查](docs/PERMISSION-AUDIT.md)。

## 開發資訊

專案使用 Chrome Manifest V3、原生 JavaScript 與 CSS，無需建置步驟。介面整合在 `www.plurk.com/EmoticonManager2` 管理頁的 iframe 內，沒有另外的 Popup 或 Side Panel。

### 檔案結構

```text
manifest.json             擴充功能資訊、權限及腳本載入設定
src/background.js         驗證 token 讀取與固定噗浪 API 請求
src/api-client.js          介面與背景訊息、圖片檔案序列化
src/upload-core.js         群組解析、逐張上傳佇列與結果核對
src/batch-view.js          選圖、預覽、排序、群組與狀態介面
src/integration.js         原生頁面掛載、切換與清理
src/plurk-adapter.js       噗浪管理頁 DOM 對應
src/content.js             管理頁路徑檢查與啟動
tests/                     模擬 API 測試與合成 DOM 測試頁
docs/                      API、權限審查與介面文案紀錄
```

### 上傳與狀態處理

圖片上傳與加入收藏分成兩個階段，依序處理。預設每個後續請求前間隔約 1 秒，這是工具的設定，不是噗浪官方公布的頻率限制。

已確認加入收藏失敗時，會保留圖片的 `hash_id`，供手動再次執行時跳過圖片上傳；若新增結果不明，會先以指定群組與 `hash_id` 讀取核對，仍無法確認則停止。401／403／429 會停止包含同步在內的後續請求；429 的 `Retry-After` 用於提示與暫時冷卻，不會自動重試，冷卻紀錄也不會持久保存。

圖片預覽使用 object URL，移除或清理時會釋放。噗浪頁面結構或 API 變更後，可能需要調整整合程式。

### 本機測試

安裝 Node.js 後執行：

```sh
node --test tests/upload-core.test.js tests/background.test.js
```

這些測試使用模擬 API 與合成驗證資料，不會連線上傳至噗浪。`tests/fixture.html` 則提供合成 DOM 的介面與生命週期檢查，不會連接真實上傳 API。

### 實際環境驗證

以下項目已由專案維護者確認在噗浪實際環境中驗證通過：

- 主頁表單 token 驗證，以及噗浪接受擴充功能背景送出的請求。
- 單張與連續多張圖片的完整上傳流程，以及空白關鍵字的自動命名結果。
- 群組讀取與刷新、空群組的實際回應，以及原生管理視窗的整合與重開行為。
- 圖片大小、尺寸、格式與關鍵字限制，以及額滿、權限與頻率限制的實際回應。
- 真實環境中的失敗重試、結果不明核對，以及中途關閉視窗的行為。
